# TestudoQ Project Brief

## Overview
TestudoQ is a modern browser extension built with ES modules that provides advanced testing utilities for web development. Its flagship feature is the gremlins testing system that simulates chaotic user interactions, now fully integrated with both popup and context menu interfaces.

## Core Features

### 1. Testing Utilities
- ✅ Context menu integration for quick access
- ✅ Value injection and clipboard operations
- ✅ Gremlins attack functionality
- ✅ Configuration management

### 2. Architecture

- ✅ MV3 compliance
- ✅ Cross-browser support
- ✅ Clean modular design

### 3. User Interface

### 4. Integration Points
