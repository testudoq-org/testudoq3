# TestudoQ Project Brief

## Overview
TestudoQ is a browser extension that provides various utilities for testing and development, including a powerful gremlins testing feature that can simulate chaotic user interactions on web pages.

## Core Features
- Context menu integration for various testing utilities
- Value injection and clipboard operations
- Gremlins attack functionality for chaos testing
- Configuration management for test scenarios

## Technical Goals
1. Maintain robust browser extension functionality
2. Support both Chrome and Firefox browsers
3. Provide configurable testing utilities
4. Enable chaos testing through gremlins integration

## Current Focus
Reactivating and improving the gremlins attack functionality, specifically:
1. Restore context menu integration
2. Ensure proper gremlins view functionality
3. Verify simulation components
4. Test integration points

## Success Criteria
- Functional context menu integration for gremlins attack
- Working gremlins attack configuration interface
- Proper simulation execution
- Reliable browser compatibility
